# Legacy Titan theme archive

This folder preserves the former GitHub Pages implementation and its generic theme assets.

It is not an active application and must not be used as a design, content, or technical dependency for the new Merkhet Ventures website. It exists only as a recoverable historical record until the new Cloudflare Pages deployment is approved.

## Contents

- `pages/` — prior homepage, 404 page, and generic theme demos
- `assets/` — theme images, styles, scripts, libraries, and source SCSS
- `php/` — unused legacy form handlers that cannot run on static GitHub Pages
- `github-pages/CNAME` — former GitHub Pages custom-domain declaration
