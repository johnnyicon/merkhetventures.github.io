# Merkhet Ventures — Minimal Scroll World Prompt

Use this shorter prompt in a fresh Codex session from the repository root:

```text

Work only inside `apps/scroll-world/`. Before making decisions, read `AGENTS.md`, `content/company-profile.md`, `content/website-content-strategy.md`, `brand/brand-brief.md`, and `apps/website/index.html`.

Treat those files as the source of truth. Let the skill interview me and make the creative and technical decisions from there. The world should express Merkhet’s central idea—transforming knowledge into wisdom for impact—with a thoughtful, grounded, materially credible feeling.

Do not modify the live website or any files outside `apps/scroll-world/`. Before generating paid Higgsfield assets, show me the proposed direction, asset count, current balance, and estimated cost, then wait for my explicit approval.
```

This intentionally leaves the scene count, visual treatment, palette, camera architecture, mobile decision, and implementation details to the Scroll World skill and the conversation. The longer [brief.md](brief.md) remains available when we want tighter direction.
