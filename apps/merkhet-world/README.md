# Merkhet World

This folder is reserved for a separate, experimental Merkhet World build using the `scroll-world` skill. It is not part of the public website unless explicitly approved.

Use `one-shot-prompt.md` as the minimal entry point for a cold-start build. The detailed `brief.md` is optional reference material, not a required prompt.

All generated images, clips, and scroll-engine files must remain within this folder.
