# Merkhet Ventures

This repository is the home for the Merkhet Ventures public website, its source material, and future web experiments.

## Structure

- `apps/website/` — the production-ready Merkhet Ventures website.
- `apps/merkhet-world/` — an isolated future Merkhet World experiment.
- `content/` — company narrative, strategy, and discovery material.
- `brand/` — brand guidance and visual references.
- `plans/` — repository and migration plans.
- `archive/legacy-titan-theme/` — the prior theme and GitHub Pages implementation, retained temporarily for reference only.

## Hosting direction

The website is being prepared for Cloudflare Pages. The live domain remains on GitHub Pages until a Cloudflare Pages preview is approved and a deliberate DNS cutover is performed.
